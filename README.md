## Setup (5 minutes)

### 1. Get your free keys
| What | Where | Cost |
|------|-------|------|
| Telegram Bot Token | [@BotFather](https://t.me/BotFather) on Telegram | Free |
| Groq API Key | [console.groq.com](https://console.groq.com) | Free |

### 2. Install Python
Download from [python.org](https://python.org) — free, one time.

### 3. Install dependency
```bash
pip install requests
```

### 4. Configure the bot
Open `manubeta_bot.py` and fill in:
```python
BOT_TOKEN  = "your-telegram-bot-token"
GROQ_KEY   = "your-groq-api-key"
```

### 5. Run her
```bash
python manubeta_bot.py
```

Then open Telegram and message your bot. She'll reply. 💙
